# Поиск клиник Краснодара

Современное веб-приложение для поиска лучших клиник Краснодара по отзывам пациентов.

## Возможности

- Поиск клиник по названию, адресу или специальности
- Фильтрация по минимальному рейтингу
- Сортировка по рейтингу, количеству отзывов или алфавиту
- Просмотр подробной информации о клинике
- Чтение отзывов пациентов
- Современный минималистичный дизайн
- Адаптивная верстка для всех устройств
- Плавные анимации

## Технологии

- React 18
- Framer Motion (анимации)
- Tailwind CSS (стили)
- SVG иконки

## Быстрый старт

### Запуск приложения

1. Откройте файл `index.html` в браузере
2. Приложение готово к использованию!

### Для разработки

Если вы хотите настроить среду разработки:

```bash
# Установите зависимости
npm install

# Запустите dev сервер
npm run dev

# Соберите проект
npm run build
```

## Использование

1. **Поиск**: Введите название клиники, адрес или специальность в поле поиска
2. **Фильтры**: Нажмите кнопку "Фильтры" для настройки параметров:
   - Выберите способ сортировки
   - Установите минимальный рейтинг с помощью слайдера
3. **Просмотр**: Нажмите на карточку клиники для просмотра детальной информации и отзывов

## Функции

### Поиск и фильтрация
- Мгновенный поиск по всем полям
- Фильтрация по рейтингу от 0 до 5 звезд
- Три варианта сортировки

### Карточки клиник
- Название и рейтинг
- Адрес и телефон
- Специальности
- Количество отзывов

### Детальная информация
- Полная информация о клинике
- Список всех отзывов пациентов
- Рейтинг каждого отзыва
- Дата публикации отзыва

## Дизайн

Приложение использует современный минималистичный дизайн:
- Чистая типографика
- Минималистичные SVG иконки (без эмодзи)
- Мягкая цветовая палитра
- Плавные анимации и переходы
- Адаптивная сетка
